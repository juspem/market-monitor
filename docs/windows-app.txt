MARKET MONITOR - WINDOWS EDITION

Requires Windows 10 or later (64-bit) and an internet connection for market data.

INSTALL
Open Market-Monitor-Setup-<version>-x64.exe and follow the installer.
Launch Market Monitor from the Start menu or desktop shortcut.
Node.js, a browser, and a terminal are not required.

USE
Choose a date range above the performance chart.
Use the Market Regime selector for rates, currencies, commodities, and other indicators.
Data comes directly from Yahoo Finance, FRED, and Cboe; it can be delayed or unavailable.
If Yahoo limits requests, wait for the displayed cooldown before pressing Retry.
Use View > Reload (Ctrl+R) to refresh the dashboard.

UPDATES
Install a newer Market Monitor installer over the existing version.
This version does not download or install updates automatically.
